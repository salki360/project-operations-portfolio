# Interview Walkthrough — NOVA Commerce (Simulation)

## 60-second introduction

“I built this self-directed project operations simulation to demonstrate how I would coordinate a small e-commerce launch. It covers a 30-day plan, 23 linked tasks, owners, status and progress, weekly reporting, a budget, risk and issue logs, user acceptance, and handover. I created a formula-driven tracker and dashboard so a reviewer can move from the summary to task-level evidence. The project and all results are fictional; I use it to show my working approach, not to claim client experience.”

## Three-minute walkthrough

1. **Outcome and assumptions:** explain the fictional storefront, 84-SKU scope, 30-day window and fixed $20,000 modeled budget.
2. **Control system:** show how owner, start/finish, dependency, status and acceptance evidence connect in the master tracker and timeline.
3. **Decision visibility:** show weekly checkpoints, budget variance, risk response and linked issues. Explain how changes would be assessed before baselines changed.
4. **Closeout:** point to UAT, readiness, handover and lessons in the dossier.
5. **AI transparency:** describe AI as drafting/consistency support; a person verifies data, decisions and communications.

## Likely questions

**Was this a real client project?** No. It is a fictional simulation built for portfolio practice.

**How did you calculate progress?** The scenario uses task completion percentages rolled up in the workbook. The weekly checkpoints are illustrative snapshots.

**Why did the budget finish below plan?** The scenario records $19,650 against $20,000, leaving $350 favorable variance. Category-level values are illustrative and the contingency reserve was unused.

**What would you improve next?** Add an explicitly documented baseline approval log, acceptance evidence links, and a post-launch monitoring dashboard if this were a real delivery.

**What AI tools did you use?** Explain only the tools actually used to create or review this portfolio. Do not imply that AI made project decisions or verified real-world facts.

## Honest resume wording

**Self-directed project operations simulation:** built a 30-day e-commerce launch plan with 23 dependent tasks, ownership, progress tracking, weekly reporting, risk/issue controls and a formula-driven budget dashboard; produced charter, SOP, status communications and handover documentation. All project data is fictional.
